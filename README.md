**Student:** Charles Zhang
**Course:** Spring-LTA2061 Tales of the City
**Assignment:** Creative Project
**Theme:** Uncivil Disagreement
**Primary Texts:** Stevenson, *The Strange Case of Dr. Jekyll and Mr. Hyde* (1886) & Foucault, "Panopticism" (1975)

---

## How to Open

Download all three files into the same folder, then open `index.html` in any modern browser. No installation or internet connection required to run — the site loads Google Fonts via CDN for typography, but degrades gracefully to Georgia serif without it.

## Files

| File | Purpose |
|---|---|
| `index.html` | All content and page structure |
| `style.css` | All styling and both visual modes |
| `script.js` | Toggle, FAQ accordion, donate button interactions |

## Usage

Click the **🌑 Hyde Mode** button in the top-right of the navbar to switch modes. Click **☀️ Jekyll Mode** to switch back.
